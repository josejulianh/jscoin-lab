Práctica 2 — Semana/Día 2

Prueba de Trabajo (Proof-of-Work) simple

Un bloque solo se añade cuando se encuentra un nonce tal que su hash empieza por un número de ceros (la dificultad). Esto hace costoso alterar la cadena.

Prototipo educativo. Esto NO es apto para producción. No tiene firmas digitales, red P2P, consenso real, recompensas ni dificultad adaptativa de Bitcoin. Solo sirve para entender el concepto de PoW.

Ejercicios (Práctica 2)

  1. Ejecuta el código con dificultad 2. Observa el nonce y el tiempo.
  2. Cambia la dificultad a 3 o 4 y vuelve a ejecutar. Compara tiempos.
  3. Pulsa “Alterar bloque 1” y comprueba que la validez pasa a falsa (el hash ya no cumple la dificultad ni el cálculo).
  4. Modifica el código para contar y mostrar cuántos hashes se calcularon al minar cada bloque.
  5. Añade un método getBalance(address) simple que recorra la cadena.
