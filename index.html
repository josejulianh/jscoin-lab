Práctica 1 — Fundamentos

Bloques y Cadena de Bloques

Un bloque agrupa datos (transacciones) y se enlaza al anterior mediante el hash. La cadena es inmutable solo si no se altera ningún bloque.

Prototipo educativo. Esto NO es apto para producción. No tiene prueba de trabajo, firmas digitales, red P2P ni consenso. Es solo para aprender las estructuras de datos.

Ejercicios

  1. Ejecuta el código y verifica que la cadena es válida.

  3. Modifica el código para añadir un método printChain() que muestre índice, hash y previousHash de forma legible.
  4. Añade 3 bloques más con datos inventados y confirma que la validez se mantiene.
